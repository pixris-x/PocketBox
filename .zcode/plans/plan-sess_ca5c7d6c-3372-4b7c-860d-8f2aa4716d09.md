在 `D:\WorkspacePerson\webTool` 新建 **Vite + Vue 3 纯前端**工具站（v1 共 9 个工具），全部浏览器本地计算、数据不出站。同时把开发规则固化为项目内的持久约束文件，后续开发与维护一律按规则执行。

## ★ 开发规则约束（AGENTS.md）
在项目根目录创建 **`AGENTS.md`**（ZCode / Claude Code 均会自动加载，作为本项目开发与维护的强制约定），并在 README 中引用。规则内容：

1. **技术栈锁定**：Vite + Vue 3 + vue-router；包管理只用 **pnpm**；语言只用 **JavaScript + SCSS，禁止引入 TypeScript**；新增依赖需评估必要性并在 README 登记。
2. **目录规范**：
   - 公共代码统一放 `src/common/` 下三个子目录：`styles/`（公共样式）、`utils/`（公共函数）、`components/`（自研 UI 组件库）。
   - **每个页面必须独立文件夹**，统一含 `index.vue`（主 vue）+ `components/`（页面私有组件）+ `styles/`（页面样式）+ `scripts/`（页面脚本）；不涉及时可省略空目录，但结构约定不变。
   - 可复用的纯算法（base64/md5/json/url/时间戳/复制/下载/主题）一律进 `common/utils`；页面专属逻辑进页面 `scripts/`，不得复制粘贴公共函数。
3. **UI 规范**：凡可用自研 UI 库组件（UiButton/UiInput/UiSlider 等）的场景**必须使用组件库**，禁止另写样式；新组件需进 `common/components` 并在 `index.js` 注册，统一使用设计 token（明暗主题变量）。
4. **路由与工具注册**：新增工具只需在 `src/data/tools.js` 加一条元数据（首页网格与路由自动生成），页面放 `views/tools/<id>/`。
5. **命名约定**：组件 PascalCase、文件 kebab-case、函数/变量 camelCase、常量 SCREAMING_SNAKE。
6. **主题**：明暗主题必须走 `data-theme` + CSS 变量，禁止硬编码颜色。
7. **未来后端**：如后续引入后端/持久化，用 .NET 10 + PostgreSQL，新增 `src/api/` 服务层通过 fetch 接入，前端结构不变；v1 不建后端、无任何请求外发。

## 技术底座
- **构建**：Vite 7 + `@vitejs/plugin-vue`，`base: './'` + Hash 路由（构建后可任意静态托管甚至本地打开）
- **依赖**：`vue`、`vue-router`、`js-md5`、`terser`（浏览器 bundle 走 Web Worker）；其余用原生 API（`crypto.getRandomValues` / `crypto.randomUUID` / Canvas）
- **vite.config.js**：配 `@` → `src` 别名，SCSS 全局注入公共变量/混入（additionalData）

## 自研 UI 组件库
SCSS 设计 token（主色/成功/警告/危险、文字/边框/背景、间距/圆角/阴影/字号），明暗主题用 `[data-theme="dark"]` 覆盖变量；`useToast` 全局反馈；组件内样式使用公共变量，保证整套风格一致。

## 9 个工具（v1）
1. **随机强密码生成**：crypto.getRandomValues 真随机；长度滑块、字符集勾选、排除易混淆字符(0O1lI)、批量生成、熵强度提示
2. **图片格式转换**：拖拽/点选上传，Canvas 转 PNG/JPEG/WebP，质量滑块、等比缩放、JPEG 透明背景填白，预览 + 大小对比 + 下载
3. **Base64 转换**：文本（Unicode 安全编解码）+ 文件（文件↔base64，可下载）
4. **MD5 哈希**：js-md5，支持文本与文件(ArrayBuffer)，输出 hex，附"非安全用途"提示
5. **JavaScript 压缩**：terser 在 Web Worker 运行（防 UI 卡顿），压缩/混淆开关，大小对比 + 节省率，复制+下载
6. **JSON 格式化/压缩**：缩进 2/4/Tab、校验报错、可选排序键、一键压缩
7. **URL 编码/解码**：encodeURIComponent/decodeURIComponent，全量编码选项
8. **时间戳转换**：秒/毫秒 ↔ 日期（本地/UTC），当前时间戳快捷按钮
9. **UUID 生成**：v4 批量生成、大小写选项、复制
